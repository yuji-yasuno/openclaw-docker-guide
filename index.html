Self-hosted AI tutorial · 2026

Slackで動く自分専用AI。
DockerでOpenClawを立ち上げる。

公式Docker経路でGatewayを起動し、Sakana.ai（Namazu）を接続し、Slackから会話するまでをコピー実行できる手順で解説します。

ステップバイステップで実装する まず全体像を見る

1. Gatewayを起動

公式イメージとComposeでポート18789まで到達します。

2. Sakana.aiを接続

Namazuを主モデルにするOpenAI互換設定です。

3. Slackで会話

Socket Modeなら公開URLは不要です。

OpenClawとは何か

チャットに住む自己ホスト型AI秘書です。設定と記憶は自分のホストに残ります。

ChatGPTとの違いChatGPTは会話相手。OpenClawは実行基盤で、Slackを窓口にして作業します。
あなた → Slack → Gateway :18789 → Sakana.ai / Workspace / Sandbox

同名プロジェクトに注意

このOpenClawはゲームではありません画面はブラウザとSlack、アセットは ~/.openclaw/workspace です。X11転送やゲームデータは不要です。
